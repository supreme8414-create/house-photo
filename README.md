# 房屋修圖器

房仲專用的手機修圖小工具：拍完物件照片，用手指塗掉「可以移動的雜物」（鞋子、衣物、電線、垃圾桶…），AI 幫你補好背景，再存回手機上架。

- **免費模式**：AI 直接在手機裡執行，照片**不會上傳**到任何地方。
- **強力模式**：把照片送到 Google Gemini 處理，效果更好，但**需要自己的 API 金鑰，且要付費**；照片會傳到 Google。

---

## 一、先在電腦上試試看

1. 在這個資料夾裡，**雙擊 `start.bat`**。
2. 出現黑色視窗與網址後，用電腦瀏覽器（Chrome / Edge）打開 `http://localhost:8080/`。
3. 用完把黑色視窗關掉即可。

> 如果黑色視窗顯示「只能本機使用」，沒關係，電腦測試不受影響。

---

## 二、真正放到手機上用（需要 HTTPS 網址）

手機用電腦的區域網路（`http://192.168...`）**只能預覽，不能安裝成 App、也不能離線使用**，因為手機要求 HTTPS 才允許。
正式使用請把整個資料夾放到免費的 HTTPS 空間。下面任選一種。

### 方法 A：GitHub Pages（免費）

1. 到 github.com 註冊帳號並登入。
2. 右上角「＋」→ **New repository**，名稱取英文，例如 `house-editor`，選 **Public**，按 Create repository。
3. 在新頁面點 **uploading an existing file**，把本資料夾裡**所有檔案與資料夾**（`index.html`、`app.js`、`engine`、`icons`…）拖進去，按 **Commit changes**。
   - 若資料夾拖曳沒有帶進子資料夾，請改用電腦版 Chrome，或一個資料夾一個資料夾上傳。
4. 進 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
5. 等 1～2 分鐘，頁面上方會出現網址：`https://你的帳號.github.io/house-editor/`。用手機開啟它。

### 方法 B：Netlify Drop（最簡單，免註冊也可先試）

1. 開 app.netlify.com/drop。
2. 把整個資料夾拖到頁面中央。
3. 幾秒後得到 `https://xxxx.netlify.app` 網址，手機開啟即可。（建議註冊登入，網址才不會過期。）

### 方法 C：Cloudflare Pages

1. 註冊 dash.cloudflare.com，進入 **Workers & Pages → Create → Pages → Upload assets**。
2. 取名後把整個資料夾拖進去，按 Deploy，取得 `https://xxx.pages.dev` 網址。

---

## 三、加到主畫面（像 App 一樣使用）

- **iPhone**：用 **Safari** 開網址 → 點下方「分享」按鈕 → **加入主畫面** → 新增。
- **Android**：用 **Chrome** 開網址 → 右上角選單「⋮」→ **安裝應用程式**（或「加到主畫面」）。

第一次使用免費模式會下載 AI 模型（檔案較大，建議連 Wi-Fi），之後就會存在手機裡，不用重複下載。

---

## 四、取得 Gemini API 金鑰（強力模式才需要）

1. 用 Google 帳號開 **aistudio.google.com/apikey**。
2. 按 **建立 API 金鑰（Create API key）**，複製那串文字。
3. 在 App 的設定頁貼上，按「測試金鑰」。金鑰只存在你自己手機的瀏覽器裡。
4. **圖像編輯需要開啟付費（綁定信用卡的計費帳戶）**。

**費用（2026-11-22 查官方定價頁）**：
- 目前預設模型 `gemini-nano-banana-2.1`：約 **US$0.034 / 張（1K 解析度）**、約 US$0.050 / 張（2K），約合新台幣 1～2 元一張。
- 官方定價頁對圖像輸出**沒有列出免費額度**。
- 價格可能調整，請以 ai.google.dev 的 Pricing 頁為準，並建議在 Google 後台設定預算上限。

---

## 五、隱私

- 免費模式：照片只在你的手機裡處理，**不上傳**。
- 強力模式：照片（或塗抹區域附近的裁切）會傳送到 Google 處理。若照片含有客戶隱私（人臉、證件、門牌），請改用免費模式或先遮掉。
- 原圖永遠不會被覆蓋，修好的是另存新圖。

## 六、合規提醒（很重要）

- **只能移除「可移動的雜物」**（鞋子、衣物、垃圾桶、電線等）。
- **不可移除或掩蓋**：壁癌、漏水、裂縫、結構損壞、窗外的嫌惡設施等影響買方判斷的事實（不動產經紀業管理條例第 21 條、公平交易法第 21 條，不實廣告責任）。
- 輸出圖預設加上小字「照片經整理示意」，建議保留。
- Gemini 產生的圖片含有 Google 的 SynthID 隱形浮水印。

---

## 常見問題

- **強力模式顯示金鑰錯誤**：重新複製金鑰，確認沒有多餘空白，且帳戶已啟用計費。
- **顯示額度用完 / 太頻繁**：稍等一下再試，或到 Google 後台查看額度。
- **沒有回傳圖片**：可能被安全機制擋下，換一張或縮小塗抹範圍。
- **更新網站後手機還是舊的**：關掉 App 重開兩次，或清除該網站資料。
