Gemini API 金鑰（強力模式用）

怎麼取得金鑰？
  1. 用電腦或手機開啟 aistudio.google.com/apikey，用 Google 帳號登入。
  2. 按「Create API key（建立 API 金鑰）」。
  3. 複製產生的金鑰（AIza 開頭的一長串），貼到上面欄位。
  4. 按「測試金鑰」，出現成功訊息就可以用了。

金鑰只存在這支手機上，不會上傳到其他地方。使用量與費用依 Google 規定計算。
